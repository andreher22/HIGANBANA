# Higanbana

Free, mobile-first fitness web app for beginners training at home or at the gym.

App fitness gratuita para principiantes. Rutinas por bloques ABCD: si solo tienes 15 minutos, haces el bloque A y el día cuenta.

> **v0.1.0** · Fase 0 (planeación) terminada · Siguiente: Fase 1 (base técnica). Ver [CHANGELOG](CHANGELOG.md).
