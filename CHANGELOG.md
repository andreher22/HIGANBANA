# Changelog

Cambios importantes de cada versión de Higanbana.
Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/);
versiones con [SemVer](https://semver.org/lang/es/). Las versiones `0.x` son previas al lanzamiento público.

## [0.1.0] - 2026-11-19 · Fase 0: planeación

### Agregado
- Repositorio con flujo Git Flow (`main` ← `develop` ← ramas por issue), plantilla de Pull Request y tablero ABCD en GitHub Projects.
- Licencia MIT para el código; marca y contenido con derechos reservados.
- Documento de requisitos con prioridades ABCD y las decisiones sobre las 6 dudas del estudio.
- 12 notas de decisión técnica (ADR).
- Modelo de datos completo con sensibilidad, fase y políticas RLS por tabla.
- Borrador del aviso de privacidad (LFPDPPP 2025).
- Acuerdos de trabajo con Itzel.
- Plantilla de ficha, glosario y primeras 20 fichas de ejercicio (con propuestas ✱ por validar).

### Pendiente
- Logo y paleta de colores (Itzel).
- Validar las propuestas ✱ de las fichas.
- Revisión legal del aviso de privacidad antes del lanzamiento.
